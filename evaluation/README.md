# Evaluation evidence

Both metric files were generated by running the published ONNX files directly
through ONNX Runtime in the captured CPU MuJoCo evaluation environment with
seed 7 and the full 175-step episode horizon.

- `standalone_metrics.json` evaluates `policy/max_height_jump.onnx` alone and
  continues through the full horizon so its final non-durable pose is visible.
- `standing_handoff_metrics.json` evaluates the jump ONNX together with
  `handoff/standing_policy.onnx` using the exact smoothstep contract in
  `handoff/manifest.json`.
- `standing_handoff_trace.json` records every 50 Hz action, contact state,
  clearance measurement, joint state, and blend coefficient for the handoff.

The evidence is one deterministic simulation rollout per configuration. It is
not a randomized robustness battery or a physical-hardware test.
